    Function: useEntityForm()¶

    useEntityForm\<TEntity, TValues>(__namedParameters): object

    Defined in: ui/src/components/settings-dialog/tabs/global/common/UseEntityForm.tsx:63

    The "list + form" state every settings tab was re-implementing: which entity is selected, whether we are creating, one value bag, and the populate / start-create / cancel / save / delete handlers around it — including the validate-then-snackbar and the error snackbar on failure.

    Extracted from the outsider and room tabs, which had this same shape spelled out field by field (see #191). Keeping it in one place also means the tabs pass a single form object to their FormCard instead of drilling every value and setter as its own prop.
