    hiveLessonActivations¶

    Get Signature¶

    get hiveLessonActivations(): Collection\<HiveLessonActivation>

    Defined in: ui/src/api-server/mongo-db-controller.ts:198

    Ledger of Hive queue openings: one row per (event, occurrence, student group) that the activator has already pushed to Hive. Its unique index is what makes the activator idempotent and safe to run in more than one replica — the insert, not a lock, decides who acts.
